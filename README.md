# 유신 F.A 시스템 홈페이지

파츠피더(부품 자동정렬 공급기) 제작 전문 기업 **유신 F.A 시스템**의 회사 홈페이지입니다.
`유신 회사 소개서.pptx` 13장의 내용과 내장 이미지를 자산으로 만들었습니다.

- **Next.js 16** (App Router) · **TypeScript** · **Tailwind CSS v4**
- 전 페이지 **정적 생성(SSG)** — `output: "export"`로 순수 HTML/CSS/JS만 떨어집니다.
  운영 서버가 필요 없어 Vercel, Netlify, 카페24, 가비아 어디에 올려도 그대로 동작합니다.
- 한국어 단일 언어 (문구를 전부 `src/data/`로 분리해 두어 영문 추가가 쉽습니다)

---

## 시작하기

```bash
npm install
npm run dev        # http://localhost:3000
```

| 명령어 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 정적 빌드 → `out/` (postbuild까지 자동 실행) |
| `npm run assets` | PPTX에서 이미지를 다시 뽑아 `public/images/`를 갱신 |

빌드 결과물은 `out/` 폴더입니다. 이 폴더 전체를 웹 루트에 올리면 됩니다.

영상을 넣으면 자동으로 섹션이 나타납니다.

export const videos: Video[] = [

### 홈 히어로 배경 영상 교체하기

첫 화면 배경은 `public/videos/hero.mp4`(1280x720, 무음, 9초 루프, 약 1.7MB)입니다.
**홈 PERFORMANCE 섹션도 같은 파일을 씁니다** — 거기서는 오버레이 없이 밝게 돌고,
히어로에서는 네이비 오버레이가 덮여 불투명도 0.38로 깔립니다.

원본 촬영본에서 아래 명령으로 만듭니다. 원본은 저장소에 두지 않습니다.

```bash
# 영상 (MAH07514.MP4 의 114초 지점부터 9초)
ffmpeg -ss 114 -t 9 -i MAH07514.MP4   -an -c:v libx264 -profile:v main -pix_fmt yuv420p   -crf 28 -preset slow -g 60 -movflags +faststart   -vf scale=1280:720 public/videos/hero.mp4

# 포스터 (영상 첫 프레임). 영상이 뜨기 전과 '움직임 줄이기'에서 이게 보입니다.
ffmpeg -ss 0 -i public/videos/hero.mp4 -frames:v 1   -c:v libwebp -quality 72 public/images/hero-poster.webp
```

- `-an` 무음 — 소리가 있으면 브라우저가 자동재생을 막습니다
- `-movflags +faststart` — 메타데이터를 앞에 두어 받는 즉시 재생됩니다
- **구간은 눈으로 고르지 말고 수치로 고릅니다.** 조건이 셋입니다 —
  ① 흔들리지 않을 것 ② 사람·물체가 안 들어올 것 ③ 피더가 돌고 있을 것.
  배경이라 화면이 흔들리면 눈에 거슬리고, PERFORMANCE 섹션에서는 밝게 보이므로
  흔들림도 지나가는 사람도 그대로 드러납니다.

  ```bash
  # (1) 흔들림 — 값이 낮을수록 조용합니다 (인접 프레임 차이의 밝기 평균)
  ffmpeg -i MAH07514.MP4 -vf "scale=320:-1,tblend=all_mode=difference,signalstats,metadata=print:key=lavfi.signalstats.YAVG:file=diff.txt" -f null -

  # (2) 사람·물체 유입 — 가장자리만 따로 잽니다
  #     전체 평균으로는 발처럼 작은 것이 안 잡힙니다(평균을 3도 못 낮춥니다)
  ffmpeg -i MAH07514.MP4 -vf "scale=640:-1,crop=iw*0.28:ih:iw*0.72:0,signalstats,metadata=print:key=lavfi.signalstats.YAVG:file=edge_right.txt" -f null -
  # 왼쪽 crop=iw*0.2:ih:0:0 · 아래 crop=iw:ih*0.25:0:ih*0.75 도 같은 식으로
  # 조용한 구간의 기준선보다 6 이상 어두워지는 지점이 "무언가 들어온" 때입니다

  # (3) 마지막은 반드시 눈으로 — 0.5초 간격 콘택트 시트
  ffmpeg -ss 114 -t 9 -i MAH07514.MP4 -vf "fps=2,scale=300:-1,tile=6x3" -frames:v 1 sheet.jpg
  ```

  | 시작 | 9초 평균 | 구간 내 최대 | 사람 | |
  |---|---|---|---|---|
  | 19초 | 6.15 | 7.16 | — | 중간에 공급이 끊깁니다 |
  | 110초 | 5.83 | 13.09 | — | **앞 3초가 카메라 이동입니다**(10.3·9.9·13.1) |
  | 119초 | 2.90 | 3.25 | **있음** | 오른쪽 가장자리에 바지와 신발(123.5초~) |
  | 114초 | 3.02 | 3.43 | 없음 | 현재 구간 |

  두 번 틀렸습니다. 110초는 눈으로 "카메라가 고정됐다"고 봐서, 119초는
  흔들림만 재고 화면에 무엇이 들어오는지는 안 봐서입니다. 세 면이 모두 깨끗한
  9초 윈도는 **시작 111~114.5초** 하나뿐이었고, 그중 흔들림이 가장 낮은 곳이
  114초입니다.

  값이 너무 낮은 곳(102~105초의 2.2~2.7)은 피더가 보이지 않는 직진 트랙
  장면입니다 — **조용하면서 피더가 돌고 있는** 구간이어야 합니다
- 포스터를 바꾸면 `src/app/layout.tsx`의 preload 경로도 같이 확인하세요.
  **구간을 바꾸면 포스터도 반드시 다시 뽑습니다** — 안 그러면 '움직임 줄이기'
  에서 영상과 다른 그림이 뜹니다

### 제품 영상 미리보기 만들기

홈 '제품 영상' 두 장은 **소리 없는 로컬 mp4**가 저절로 돕니다
(`public/videos/preview-*.mp4`). 누르면 그때 유튜브로 바뀝니다.

> ⚠️ 한때 유튜브 임베드에 `autoplay&mute&loop&controls=0` 을 걸어 미리보기를
> 만들었는데, 파라미터로 UI 를 아무리 눌러도 플레이어 자체의 결(로딩 화면,
> 루프 이음매, 화질 전환)이 남아 "유튜브 미리보기"로 보였습니다.

```bash
# 금속 부품 정렬 (유튜브 _zG4dYTCWpc)
ffmpeg -ss 14 -t 7 -i 더블유비.MP4   -an -c:v libx264 -profile:v main -pix_fmt yuv420p   -crf 31 -preset slow -g 48 -movflags +faststart   -vf scale=1280:720 public/videos/preview-metal-parts.mp4

# 볼 내부 선별 지그 (유튜브 KiiYXbIajog)
ffmpeg -ss 53 -t 7 -i MAH05268.MP4   -an -c:v libx264 -profile:v main -pix_fmt yuv420p   -crf 31 -preset slow -g 48 -movflags +faststart   -vf scale=1280:720 public/videos/preview-bowl-jig.mp4
```

- **원본 촬영본은 저장소에 없습니다.** `yusin-web` 바로 위 폴더의
  `더블유비.MP4` · `MAH05268.MP4` · `MAH07514.MP4` · `00093.MTS` 입니다.
  그 파일이 없으면 다시 만들 수 없습니다
- **해상도를 원본 그대로(1280×720) 둡니다.** 한때 640×360으로 줄였는데, 카드가
  487×274로 보이므로 레티나(2x) 화면에서는 0.66배로 늘어나 뭉개졌습니다.
  1280×720이면 1.31배라 또렷합니다. 한 편 **1MB 안쪽**이고, 그 섹션까지
  내려와야 받으므로(`preload="none"` + IntersectionObserver) 첫 화면
  전송량과는 무관합니다
- `-an` 무음 — 소리가 있으면 브라우저가 자동재생을 막습니다
- 새로 만들면 `src/data/videos.ts` 의 `preview` 에 경로를 적습니다.
  **그 필드가 있는 영상만 홈에 올라갑니다**(`featuredVideos`)

**유튜브 영상 ↔ 원본 촬영본 대조표** (썸네일을 프레임과 맞춰 확인했습니다)

| `DzUOtS_O2ko` | 소형 부품 정렬 · 에어 선별 | **없음** (검정·연두 볼 + 에어 노즐 장면이 원본 넷에 없습니다) | — |

## 문의 폼 설정 (오픈 전 필수)

폼은 서버 없이 **Web3Forms**로 전송합니다. 무료 250건/월.

1. <https://web3forms.com> 에서 문의를 받을 이메일 주소를 입력하면 access key가 메일로 옵니다.
2. `.env.local.example`을 `.env.local`로 복사하고 키를 채웁니다.

   ```
   NEXT_PUBLIC_FORM_ENDPOINT=https://api.web3forms.com/submit
   NEXT_PUBLIC_FORM_ACCESS_KEY=여기에-발급받은-키
   ```

3. Vercel에 배포한다면 프로젝트 **Settings → Environment Variables**에도 같은 값을 넣습니다.

키가 비어 있으면 폼은 "문의 폼이 아직 설정되지 않았습니다. 전화나 이메일로 연락 부탁드립니다."
라고 안내합니다. 잘못 보내지는 일은 없습니다.

access key는 브라우저에 노출되지만 안전합니다. 등록된 수신 이메일로만 전달되고,
키만으로는 수신 주소를 바꾸거나 기존 문의를 읽을 수 없습니다.

**다른 서비스로 바꾸려면** `src/lib/inquiry.ts`의 `submitInquiry()` 한 곳만 고치면 됩니다.

## 이미지 자산

`npm run assets`가 `../유신 회사 소개서.pptx`를 열어 `public/images/`를 만듭니다.
(`scripts/extract-assets.mjs`의 `PLAN` 배열이 어떤 이미지를 어디로 보낼지 정합니다.)

원본 사진이 1024×768급 오래된 사진이라 **확대하지 않고** webp 변환 + 상한 리사이즈만 합니다.
제품 카드도 꽉 채워 자르지 않고(`object-contain`) 여백을 둔 레이아웃입니다.

스크립트가 자동으로 처리하는 것들:

- 로고 흰 배경을 투명으로 바꾸고 여백을 잘라내 `images/logo.png`로 저장 (400×52)
- **로고 마지막 M 복원** — 아래 참고
- 파비콘(`src/app/icon.png`, `apple-icon.png`)과 OG 이미지 생성
- 컨트롤러 사진은 단독 사진이 없어 우레탄 코팅 사진에서 OPC-50TH 부분을 잘라 180° 회전

### 로고 마지막 M 복원

PPT 안의 로고 원본(`image3.png`)은 **파일 끝이 잘려 있습니다.** 아랫줄
"FEEDING AUTOMATION SYSTEM"의 마지막 M에서 오른쪽 기둥이 중간 아래로 통째로
비어 있어(y39~45는 4px, y46~51은 1px) 그대로 쓰면 "SYSTE"처럼 깨져 보입니다.
복원할 픽셀이 원본에 없습니다.

`scripts/extract-assets.mjs`의 `repairLogo()`가 **같은 줄 "AUTOMATION"의 M을
통째로 떼어다 붙여** 이 글자를 되살립니다. 같은 서체·같은 크기로 래스터라이즈된
글자라 이식해도 티가 나지 않습니다.

- 떼어 올 M: `x 266..277` (12px) — 태그라인 잉크 덩어리를 스캔해 확인한 범위
- 붙일 자리: `x 388` — 앞 글자 E가 385에서 끝나고 글자 간격이 2px
- 지우개는 반드시 **불투명**이어야 합니다. `dest-out`은 소스가 불투명한 곳을
  지우므로 투명한 사각형을 넣으면 아무것도 지워지지 않습니다 (실제로 겪은 버그).
- 끝에 투명 여백 3px을 붙여 **403×52**로 만듭니다. M이 캔버스 끝에 붙어 있으면
  브라우저가 줄여 그릴 때 마지막 기둥이 흐려져 또 잘려 보입니다.

복원 뒤 스크립트가 **태그라인 마지막 글자의 폭을 다시 재서 12px가 아니면 경고**를
찍고 원본을 그대로 둡니다. "고쳤다"고 하고 안 고쳐지는 일이 없게 하려는 것입니다.

다른 글자(F·E·E·D·I·N·G·A·U·T·O·M·A·T·I·O·N·S·Y·S·T·E)는 하나씩 픽셀로 확인했고
**전부 온전합니다. 손상은 마지막 M 하나뿐입니다.**

**유신 측에서 벡터 원본(AI/SVG)을 받으면 `repairLogo()`를 지우고
`images/logo.png`만 갈아 끼우면 됩니다.** (이때 `Header.tsx`·`Footer.tsx`의
`width`/`height`도 새 파일 치수로 고쳐야 합니다)

### 거래처는 왜 로고가 아니라 글자인가

PPT 13페이지에는 거래처 로고가 4열 × 7행 표(720×480) 한 장으로만 들어 있었습니다.
낱장으로 잘라 써 봤지만 로고당 150×45px에 배경색도 제각각이라 지저분했고,
인터넷에서 대체 로고를 받아 보려 했으나 **28개사 중 정식으로 구할 수 있는 곳이
7~10개뿐**이었습니다. 중소 B2B 업체는 로고 파일이 공개돼 있지 않고,
흔한 상호(대영·에스테크·아하테크 등)는 엉뚱한 회사 로고를 올릴 위험도 있습니다.

그래서 **회사명을 같은 서체·같은 크기로 렌더**합니다(`src/components/ClientGrid.tsx`).
어느 해상도에서도 선명하고, 상표 오인 위험이 없으며, 34개사가 한 그리드에 가지런히 들어갑니다.

나중에 유신 측에서 **거래처 로고 파일과 게재 동의**를 함께 받으면,
`ClientGrid`를 이미지 그리드로 바꾸면 됩니다.

### GitHub Pages (현재 운영 방식)

**main 에 푸시하면 자동으로 올라갑니다.** 운영 서버가 없고, 도메인 값
말고는 들어가는 비용이 없습니다.

```
가비아      yusin.co.kr 도메인 + DNS 레코드
GitHub      .github/workflows/deploy.yml 이 빌드해서 Pages 로 배포
Web3Forms   문의 폼이 브라우저에서 바로 POST (운영 서버 불필요)
```

처음 한 번만 해 두면 되는 설정입니다.

**1. 저장소 Settings > Pages**

- Source 를 **GitHub Actions** 로 (Deploy from a branch 아님)
- Custom domain 에 `yusin.co.kr` — DNS 검사 통과까지 몇 분 걸립니다
- 통과하면 **Enforce HTTPS** 체크 (인증서는 Let's Encrypt 로 자동 발급)

**2. 가비아 DNS 관리**

| 타입 | 호스트 | 값 |
|---|---|---|
| A | @ | `185.199.108.153` |
| A | @ | `185.199.109.153` |
| A | @ | `185.199.110.153` |
| A | @ | `185.199.111.153` |
| CNAME | www | `jaewonlee1205.github.io.` |

A 레코드 네 개는 GitHub Pages 고정 IP입니다. 넷 다 넣어야 한 대가 죽어도
사이트가 삽니다.

**건드리면 안 되는 것**

- `public/CNAME` — 도메인이 적힌 파일입니다. GitHub Pages 설정 화면에서만
  도메인을 넣으면 **다음 배포 때 날아갑니다**. 이 파일이 매 빌드마다
  `out/` 으로 복사돼 설정을 유지합니다.
- `public/.nojekyll` — 빈 파일이지만 지우면 안 됩니다. 내보낸 결과에
  `_next/` 처럼 밑줄로 시작하는 경로가 있는데 Jekyll 은 그런 것을 무시해서,
  브랜치 배포로 바꾸는 순간 CSS·JS 가 전부 404 가 됩니다.
- `src/data/site.ts` 의 `url` — 사이트맵·robots·OG 태그·JSON-LD 가 전부
  이 값 하나를 씁니다.

### 일반 웹호스팅 (카페24, 가비아 등)

```bash
npm run build
```

`out/` 폴더 안의 내용을 전부 웹 루트에 FTP로 올리면 끝입니다.
`trailingSlash: true`라 모든 페이지가 `폴더/index.html` 형태로 떨어져,
Apache·Nginx 기본 설정에서 별도 rewrite 없이 동작합니다.
